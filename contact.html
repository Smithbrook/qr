Contact

Something broken, missing, or just on your mind?

NoFluffQR is built and run by one independent maker, so replies aren't instant — but every message gets read, usually within 24–48 hours (often sooner).

support@NoFluffQR.com Bug reports, feature requests, "is this code safe" questions — all welcome here.

Before you write in

  • If a QR code isn't scanning, check the destination link works on its own first — most scan failures are broken links, not broken codes.
  • Include the browser and device you're using if something looks visually off.
  • Press requests and partnership pitches are read too, just slower.
